# Layout Switcher

Расширение GNOME Shell, которое запоминает раскладку клавиатуры для каждого
приложения, а в Google Chrome — отдельно для полей каждого сайта; адресная
строка Chrome, логины и пароли всегда начинают с английской раскладки.
Запомненное видно и правится в окне настроек расширения и во всплывающем окне
расширения Chrome.

## Что делает

- При фокусе окна включает раскладку, которую вы в последний раз выбрали
  в этом приложении. Все окна приложения делят одно значение, оно переживает
  закрытие окон, перезапуск приложения, перелогин и перезагрузку.
- Приложению, для которого ничего не запомнено, достаётся первая раскладка
  из списка GNOME (Настройки → Клавиатура).
- Диалоги (выбор файла и т. п.) делят память со своим приложением.
- В Chrome: в полях страниц — своя раскладка для каждого сайта, в адресной
  строке, полях логина и пароля — английская.
- Переключает раскладку штатным механизмом GNOME, поэтому индикатор на панели
  всегда показывает реальную раскладку.

## Требования

- Debian 12 с GNOME Shell 43, сессия X11 (Wayland и другие версии GNOME не
  поддерживаются), процессор x86-64 (amd64).
- Для раздельных раскладок в браузере — Google Chrome 120 или новее (не
  Chromium). Без Chrome всё остальное работает: раскладка запоминается по
  приложениям.

Go и другие инструменты сборки не нужны: в архиве всё уже собрано.

## Установка

1. Скачайте со страницы
   [Releases](https://github.com/xstreamka/layout-switcher-releases/releases) два файла
   последнего релиза: `layout-switcher_<версия>.tar.gz` и `SHA256SUMS`.
   Или в терминале (подставьте номер версии):

   ```bash
   VERSION=1.0.0
   curl -LO "https://github.com/xstreamka/layout-switcher-releases/releases/download/v$VERSION/layout-switcher_$VERSION.tar.gz"
   curl -LO "https://github.com/xstreamka/layout-switcher-releases/releases/download/v$VERSION/SHA256SUMS"
   ```

2. Проверьте архив, распакуйте и запустите установку:

   ```bash
   sha256sum -c SHA256SUMS
   tar -xzf layout-switcher_$VERSION.tar.gz
   cd layout-switcher-$VERSION
   ./install.sh
   ```

   `sha256sum -c` должен вывести `layout-switcher_<версия>.tar.gz: ЦЕЛ`
   (или `OK`). Если нет — архив скачался с ошибкой, скачайте заново.

   Скрипт копирует файлы в домашний каталог (sudo не нужен):
   - расширение GNOME — в
     `~/.local/share/gnome-shell/extensions/layout-switcher@example.com/`;
   - расширение Chrome — в `~/.local/share/layout-switcher/browser/`;
   - мост между Chrome и GNOME — в
     `~/.local/lib/layout-switcher/layout-switcher-bridge` и регистрирует его
     в Chrome (`~/.config/google-chrome/NativeMessagingHosts/layout_switcher.bridge.json`).

   После установки распакованную папку и архив можно удалить.

3. Перезапустите GNOME Shell: Alt+F2 → `r` → Enter. Затем включите
   расширение:

   ```bash
   gnome-extensions enable layout-switcher@example.com
   ```

4. Chrome — в каждом профиле, где нужны раздельные раскладки:
   1. Откройте `chrome://extensions` и включите «Режим разработчика».
   2. «Загрузить распакованное расширение» → папка
      `~/.local/share/layout-switcher/browser` (скрытую папку `.local` в окне
      выбора показывает Ctrl+H). ID расширения постоянный:
      `iidcidginfikmkbmoihponjkhdcdockj`.
   3. Для окон инкогнито: «Сведения» расширения → «Разрешить в режиме
      инкогнито».

   Chrome подхватывает мост сам, перезапускать браузер не нужно. Если политика
   организации запрещает устанавливать расширения, ID
   `iidcidginfikmkbmoihponjkhdcdockj` нужно внести в политику
   `ExtensionInstallAllowlist`.

## Обновление

1. Скачайте и проверьте архив новой версии, распакуйте и запустите
   `./install.sh` (как в «Установке», шаги 1–2) — новые файлы заменят
   прежние, запомненные раскладки сохранятся.
2. Перезапустите GNOME Shell: Alt+F2 → `r` → Enter.
3. В `chrome://extensions` нажмите кнопку обновления ⟳ у Layout Switcher
   (в каждом профиле).

## Удаление

Из распакованной папки любой версии:

```bash
./install.sh uninstall
```

Если распакованную папку уже удалили — скачайте архив любой версии со
страницы [Releases](https://github.com/xstreamka/layout-switcher-releases/releases),
распакуйте и запустите в нём `./install.sh uninstall`.

Скрипт выключает расширение GNOME, удаляет его, копию расширения Chrome,
мост и его регистрацию в Chrome. Запомненные раскладки
(`~/.config/layout-switcher/`) остаются — удалите эту папку вручную, если они не
нужны. Само расширение Chrome удаляется в `chrome://extensions` → Layout Switcher
→ «Удалить» (в каждом профиле).

## Что запоминается

Запоминаются только ручные переключения:

- **Alt+Shift** в окне приложения — для этого приложения.
- **Выбор в меню индикатора раскладки** на панели — для приложения, которое
  было в фокусе до открытия меню.
- **Super+Space** (попап выбора раскладки) — для приложения, которое было
  в фокусе до открытия попапа.

Не запоминаются, и после закрытия возвращается раскладка приложения:

- переключения в обзоре (Super, поиск);
- переключения в системных диалогах: Alt+F2, запрос пароля, диалог
  выключения и т. п.;
- переключения при открытых других меню панели (календарь, системное меню),
  в Alt+Tab;
- переключения, когда в фокусе нет окна (клик по рабочему столу, все окна
  свёрнуты).

## Chrome: адресная строка и поля страниц

- **Адресная строка и интерфейс браузера** (кнопки, меню, сама страница вне
  полей ввода, диалоги «Сохранить как», печать) **ничего не запоминают**: при
  входе всегда включается первая раскладка из списка GNOME (обычно
  английская). Ручной выбор держится, пока вы в том же месте (то же окно, та
  же вкладка, адресная строка или страница), и сбрасывается при переходе
  в поле, на другую вкладку, между адресной строкой и страницей, при
  переходе по ссылке и при уходе в другое окно.
- **Поля ввода на страницах** — память **для каждого сайта** своя,
  по умолчанию — `ru` (если её нет в списке — первая). Сайт — адрес вкладки
  без `www.`: `mail.yandex.ru` и `yandex.ru` — разные сайты, `www.github.com`
  и `github.com` — один. Поле во встроенном фрейме (редактор, комментарии)
  относится к сайту вкладки.
- **Поля паролей и логинов** — всегда `us` (если её нет в списке — первая),
  ничего не запоминают. Логином считается поле почты или имени пользователя
  (по его атрибутам) и ближайшее текстовое поле перед паролем; «Имя» и
  «Фамилия» в форме регистрации остаются обычными полями сайта. Пароль,
  показанный кнопкой «глаз», становится обычным полем сайта.
- **Инкогнито** — отдельной памяти нет: поле получает раскладку этого сайта из
  обычной памяти, если она запомнена, иначе `ru`. Переключения в инкогнито
  ничего не запоминают (на диск не пишется), но выбор держится, пока вы в том
  же поле. Для этого расширению нужно «Разрешить в режиме инкогнито»; без
  этого окно инкогнито расширению не видно и переключения в нём просто не
  запоминаются.
- **Веб-приложения Chrome и окна расширений** (Gmail, YouTube как приложения,
  менеджер паролей и т. п.) — как любое другое приложение: одна память на
  приложение.

Пока мост или расширение Chrome не установлены или не работают, Chrome ведёт
себя как обычное приложение: одна раскладка на всё.

Из страниц наружу уходит только имя сайта и признаки «поле / не поле»,
«пароль», «инкогнито». Ни текст, ни нажатия клавиш, ни полные адреса страниц
не передаются; имена сайтов из инкогнито никуда не записываются.

## Просмотр и правка запомненного

- **Окно настроек GNOME** — шестерёнка у Layout Switcher в приложении
  «Расширения» или `gnome-extensions prefs layout-switcher@example.com`.
  Разделы «Приложения» и «Google Chrome» (запомненные сайты), поиск, выбор
  раскладки в строке, «Забыть» и «Забыть всё».
- **Всплывающее окно Chrome** — клик по значку Layout Switcher на панели Chrome
  (если значка не видно — меню расширений, значок пазла, там его можно
  закрепить). «Текущая вкладка» — раскладка полей текущего сайта (её можно
  задать заранее), «Сайты» — все запомненные сайты с поиском и «Забыть все
  сайты». Пока окно открыто, переключения раскладки в Chrome не запоминаются —
  можно набрать имя сайта в поиске, не меняя память.

В обоих окнах первый пункт выбора — «По умолчанию» (то, что действует, пока
ничего не запомнено); выбрать его — то же, что «Забыть». Новая запись
приложения появляется только от переключения раскладки в нём; запись сайта
можно задать и заранее.

## Данные

- `~/.config/layout-switcher/apps.json` — запомненные раскладки
  (`{"приложение или сайт": "раскладка"}`). Смотреть и править их удобнее
  в окнах выше. Руками файл можно править только при выключенном расширении:
  во время работы оно перезапишет ваши правки. Если файл окажется битым, он
  переименовывается в `apps.json.broken`, и память начинается с пустой.
- `~/.config/layout-switcher/state.json` — исходное значение встроенного режима
  GNOME «своя раскладка для каждого окна». Этот режим спорит с расширением,
  поэтому при включении расширение его выключает, а при выключении —
  возвращает как было.

## Известные ограничения

- Только GNOME Shell 43 на X11 (Debian 12); Wayland не поддерживается.
- Раздельные раскладки по сайтам — только в Google Chrome. Firefox, Chromium,
  Яндекс Браузер — как обычные приложения: одна раскладка на всё окно.
- Расширение Chrome не работает на страницах `chrome://`, во встроенном
  просмотрщике PDF, в DevTools, в Chrome Web Store и на страницах не по
  `http`/`https` (например, `file://`): там, в том числе в полях, действует
  правило адресной строки — первая раскладка, ничего не запоминается.
- В окне Chrome, которого расширение не видит (инкогнито без «Разрешить
  в режиме инкогнито», профиль без расширения), ручной выбор держится и после
  смены вкладки — до ухода в другое окно.
- Alt+Shift в первые доли секунды после клика со страницы в адресную строку
  может отнестись к странице и тут же откатиться на первую раскладку.
- Расширение Chrome ставится как распакованное, поэтому нужен «Режим
  разработчика» в `chrome://extensions`.

## Если что-то не работает

Ошибки расширения GNOME и моста — в журнале:

```bash
journalctl --user -f -o cat /usr/bin/gnome-shell | grep layout-switcher
journalctl --user -f | grep layout-switcher-bridge
```

Ошибки расширения Chrome — в `chrome://extensions` → Layout Switcher →
«Ошибки».
